# 🎨 쏙쏙 순서 맞추기 생각 워크북 (초등학교 3학년)

초등학교 3학년 교육과정(과학, 보건/도덕, 실과/국어)과 연계된 **그림카드 순서 맞추기 인터랙티브 학습지 및 A4 출력 프로그램**입니다.

---

## 🌟 프로그램 핵심 특징

1. **초등 3학년 눈높이 교육과정 12개 주제 수록**
   - **과학 (생물의 한살이 & 계절)**: 배추흰나비의 한살이, 개구리의 성장 과정, 강낭콩의 자람, 사과나무의 사계절
   - **보건 / 생활 / 안전**: 올바른 분리배출, 충치 예방 3분 양치질, 올바른 손 씻기 6단계, 횡단보도 안전 수칙
   - **실과 / 미술 / 국어**: 맛있는 샌드위치 만들기, 종이 개구리 접기, 꿀벌의 생태와 꿀 만들기, 학교 도서관 이용 순서

2. **순서 맞추기 구성 (최소 2단계 ~ 최대 5단계)**
   - **1단계(시작 🚩)**과 **마지막 단계(완성 🏁)**는 친절하게 고정되어 기준을 잡아줍니다.
   - 가운데 들어갈 2~5개의 중간 순서 카드가 무작위로 섞여 출제됩니다.
   - 각 카드는 굵은 원형 번호(①, ②, ③...)가 부여되어 있습니다.

3. **두 가지 방식 완벽 지원 (오려 붙이기 ✂️ & 번호 쓰기 ✏️)**
   - **번호 쓰기**: 빈칸의 `번호: ( ? ) 번` 란에 연필로 번호(1 또는 ①)를 적어 순서를 완성할 수 있습니다.
   - **오려 붙이기**: 하단 보기 카드의 가위 점선(`✂️`)을 따라 오린 뒤 풀로 붙여 완성할 수 있습니다.
   - **디지털 학습 모드**: PC나 태블릿에서는 마우스 드래그 앤 드롭 또는 카드 터치/클릭으로 빈칸에 쏙 넣을 수 있습니다.

4. **학년, 반, 번호, 이름 및 확인란 완비**
   - 학습지 상단에 초등학교 3학년 맞춤 정보 기입란이 깔끔하게 배치되어 있습니다.
   - 웹 화면에서 미리 입력하고 인쇄해도 글자가 그대로 선명하게 출력됩니다.

5. **완벽한 A4 인쇄 레이아웃 지원**
   - 브라우저 인쇄(`Ctrl + P` 또는 `🖨️ 학습지 인쇄하기` 버튼) 시 조작 버튼, 웹 툴바가 자동으로 숨겨지고 깔끔한 A4 종이 학습지로 출력됩니다.

6. **원클릭 차시 선택 & 무한 문제 생성기**
   - **기본 제공 차시**:
     - 1차시: 신비로운 생물의 한살이 탐구 (과학 4문제)
     - 2차시: 스스로 척척! 바르고 건강한 생활 (보건/도덕 4문제)
     - 3차시: 조물조물 만들기와 이야기의 흐름 (실과/국어 4문제)
   - **선생님 맞춤 생성기**: 한 차시당 **3문제 / 4문제 / 5문제**를 자유롭게 선택하여 새로운 문제를 무작위로 무한 생성할 수 있습니다.

7. **100% 독립 실행 & 오프라인 지원**
   - 별도의 프로그램 설치나 서버 실행, 인터넷 연결 없이 `index.html` 파일을 더블 클릭하면 바로 작동합니다.
   - 모든 그림은 고해상도 SVG 벡터로 직접 그려져 인쇄 시 번짐 없이 선명합니다.
   - 효과음 또한 Web Audio API를 활용해 내장 합성음으로 재생됩니다.

## 🚀 사용 방법

1. 본 폴더에 있는 **`index.html`** 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 웨일(Whale) 등의 브라우저로 엽니다.
2. 상단 툴바 기능을 활용합니다:

   - **✨ 채점하기**: 화면에서 푼 문제의 정답 여부를 확인하고 축하 효과와 소리를 듣습니다.
   - **🔄 순서 섞기**: 카드 순서를 새롭게 무작위로 섞습니다.
   - **💡 정답 보기**: 교사용 정답 및 풀이 순서를 확인합니다.
   - **⚙️ 문제 수 / 난이도 맞춤 생성**: 3~5문제 크기의 새로운 학습지를 즉석에서 만듭니다.
